# Literature Survey

## 1. Introduction

Machine learning has increasingly been applied to healthcare prediction and classification tasks. Research in this area has demonstrated that clinical and diagnostic parameters can be used to develop models capable of identifying patterns associated with disease risk.

This project studies the application of multiple machine learning algorithms to four disease prediction tasks: Diabetes, Heart Disease, Chronic Kidney Disease, and Breast Cancer.

The literature review focuses on existing machine learning approaches, their datasets, algorithms, evaluation methods, and limitations. The review is used to establish the research background and identify the gap addressed by the proposed unified system.

## 2. Literature Review

**Conference:** ICERCS 2024

**DOI:** 10.1109/ICERCS63125.2024.10895576

## 4. Observations from Literature

The reviewed research indicates several important observations:

1. Machine learning can be applied to clinical and diagnostic parameters for disease prediction.
2. Different diseases require different feature sets and preprocessing strategies.
3. Multiple classification algorithms can produce different levels of predictive performance.
4. Comparative evaluation is important when selecting a suitable model.
5. Advanced AI techniques such as deep learning provide opportunities for future research.
6. Healthcare prediction systems require careful interpretation because predictive output does not automatically represent clinical diagnosis.
7. Dataset quality, feature selection, preprocessing, and evaluation methodology can significantly influence model performance.

---

## 5. Identified Research Gap

Based on the reviewed literature, many existing studies concentrate on a particular disease or a specific machine learning approach.

A unified academic system that combines multiple disease prediction tasks, disease-specific preprocessing, comparative evaluation of several machine learning algorithms, independent best-model selection, and web-based deployment provides an opportunity to integrate these aspects into one reproducible workflow.

The proposed project addresses this gap by developing a unified platform for four disease-risk prediction tasks:

- Diabetes
- Heart Disease
- Chronic Kidney Disease
- Breast Cancer

The project further extends the workflow through systematic model comparison and web-based interaction.

## 6. Proposed Research Contribution

The proposed system contributes through:

| Contribution | Description |

| Comparative Modelling | Evaluation of six machine learning algorithms |
| Disease-Specific Processing | Preprocessing adapted to individual datasets |
| Best-Model Selection | Independent selection for each disease |
| Reproducibility | Structured data, training, evaluation, and testing workflow |
| Web Integration | Prediction through a web-based application |
| Responsible AI | Clear distinction between risk assessment and medical diagnosis |

---

## 7. Research Significance

The literature establishes that machine learning can provide useful computational approaches for healthcare-related prediction and classification. However, responsible implementation requires appropriate preprocessing, transparent evaluation, awareness of dataset limitations, and clear communication of system boundaries.

This project therefore focuses on developing a research-oriented prototype rather than presenting the system as a clinically validated diagnostic tool.
