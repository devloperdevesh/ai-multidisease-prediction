# Initial User Interface Design

## 1. Product

MediPredict AI

The interface is planned as a modern medical-AI dashboard for preliminary disease-risk prediction.

## 3. Main UI Sections

### Header

- I.T.S branding/logo
- MediPredict AI
- Dashboard navigation
- Research/About section

### Hero Section

The hero section communicates:

AI-powered preliminary risk prediction for multiple diseases.

### Disease Cards

Four disease cards:

- Diabetes
- Heart Disease
- Chronic Kidney Disease
- Breast Cancer

### Prediction Workspace

The selected disease displays its relevant input parameters.

Each field should contain:

- Clear label
- Appropriate unit
- Validation
- Input guidance

### Result Panel

The result panel will contain:

- Risk classification
- Risk probability/score where supported
- Selected model
- Safety message
- Text-to-speech result

### Analytics

Planned charts:

- Accuracy comparison
- Precision comparison
- Recall comparison
- F1-Score comparison
- ROC-AUC comparison

Charts will use actual experimental results.

## 4. Voice Support

Browser-native speech capabilities are planned for:

- Voice input where practical
- Reading prediction results aloud

No paid external voice API is required for the planned browser-native implementation.

## 5. Responsive Design

The final interface will support:

- Desktop
- Tablet
- Mobile

## 6. Safety

The interface must clearly communicate:

This system provides preliminary risk assessment and is not a confirmed medical diagnosis.

The interface must never present model output as clinical certainty.
