# Project Type

## Academic Major Research Project

MediPredict AI is an Artificial Intelligence and Machine Learning based academic major research project with a healthcare application domain.

The project combines research and software engineering.

The research component includes:

- Literature review
- Research-gap identification
- Public dataset preparation
- Disease-specific preprocessing
- Comparative model evaluation
- Performance analysis

The engineering component includes:

- Reusable Python modules
- Model training workflows
- Prediction services
- Flask backend
- React frontend
- Testing
- Deployment

The project is not intended to function as an autonomous clinical diagnostic system.

Its purpose is to investigate and demonstrate preliminary disease-risk prediction using publicly available structured datasets.

Primary Domain: Artificial Intelligence / Machine Learning

Application Domain: Healthcare Analytics

Project Nature: Research + Software Engineering

Deployment: Web-based prototype
