# SDG Mapping, Legal, Cultural and Environmental Relevance

## 1. SDG 3 - Good Health and Well-Being

MediPredict AI aligns with SDG 3 by exploring machine learning techniques for health-related risk prediction. The project demonstrates how structured health-related data can be processed and evaluated using computational methods. It is an academic decision-support experiment rather than a clinical diagnostic service.

## 2. SDG 9 - Industry, Innovation and Infrastructure

The project aligns with SDG 9 through integration of artificial intelligence, machine learning, software engineering, web technologies, model evaluation and deployment into one digital platform.

## 3. Legal Considerations

Dataset licenses and source requirements should be respected. If the system is extended to real patient information, appropriate privacy, security, consent, data-protection and healthcare regulations would become necessary.

The academic prototype should not present predictions as confirmed medical diagnoses.

## 4. Cultural Considerations

Health-related communication should be understandable and respectful to diverse users. The interface should avoid discriminatory assumptions and should communicate the limitations of machine learning predictions.

## 5. Environmental Relevance

The project uses structured tabular datasets and conventional machine learning models. Its computational requirements are relatively modest compared with large-scale deep learning systems.

Training can be performed using ordinary computing hardware.

## 6. Sustainability

Reproducible software development, modular code, automated testing, version control and documented datasets support sustainable development.

The modular architecture also allows future expansion without rebuilding the complete system.

## 7. Responsible AI

Important principles include:

- Clear limitations
- Appropriate evaluation
- Transparent data sources
- No unsupported medical claims
- Human oversight
- Protection of sensitive information
- Awareness of dataset bias
- Awareness of population representativeness
